# Volthera Studio — GitHub Pages

Static responsive English portfolio. No build required.

Before publishing:
- Replace the contact preview in index.html with a real support email and mailto link.
- Replace the showcase placeholder with actual VFX screenshots, videos and product links. The decorative brand art is not a product sample.

Deployment:
1. Create a public GitHub repository named volthera-studio.
2. Upload index.html and .nojekyll to the repository root.
3. Open Settings > Pages; choose Deploy from a branch, main, /(root).
4. Your public address will be https://YOUR_USERNAME.github.io/volthera-studio/.
5. Check your contact details and work samples before putting this URL in Unity.
